## ✨ 一、核心痛点与功能亮点

### 1. 解决传统长图拼接的四大痛点
| 传统拼接工具痛点 | 《台词拼图》解决方案 |
| :--- | :--- |
| **整图堆叠冗长**：把每张截图的整幅画面都拼进去，图片极长且重点分散 | 默认采用**「首图全画幅 + 后续仅拼字幕条」**经典电影台词长图模式，兼顾故事氛围与紧凑阅读体验 |
| **各平台字幕高低不一**：B站、Netflix、竖屏短剧、游戏对话字幕位置不同，固定比例容易切掉半截字 | 提供**「全局滑块实时联调 + ✨ 智能边缘识别定位 + 单张可视化手势精修（0%~100% 全量程）」**三级裁剪能力 |
| **精修时手指或标签挡字**：拖动裁剪线时标签盖住台词底边，看不清有没有切到字 | 独创**「1.5dp 双色纤细标尺线 + 外侧暗区百分比标签 + 独立 ±1% 步进微调键」**，保留区视野 **100% 无遮挡** |
| **漏截字幕或需加旁白**：关键画面没截上字幕，或者想自己补写一句吐槽/注解 | 单张分镜精修内置**「电影级白字黑边双层描边台词补写」**，直接叠印在该分镜底部 |

### 2. 核心功能全览

- **📸 多渠道极速导入与分镜管理**
  - **相册多选导入**：支持在应用内一键调起系统相册批量勾选多张截图按序导入。
  - **系统相册直接「分享」拉起**：在手机相册选好截图后，直接点系统**「分享 ➡️ 台词拼图」**即可秒速载入并自动排好分镜。
  - **内置电影样片体验**：首次打开自带 4 张双语电影感示例分镜，随时可点 **「🎬 载入示例」** 零门槛体验全部功能。
  - **分镜顺序自由调整**：横向分镜轨道直观展示 `#1 主画面`、`#2 字幕条*` 角标，支持 `◀` / `▶` 左右调序、单张删除与一键清空。

- **✂️ 三种拼接模式 + 三级精准裁剪**
  1. **首图全画幅 + 后续字幕（默认）**：第 1 张保留主画面与台词，第 2~N 张仅截取底部字幕条无缝接续。
  2. **纯字幕台词本**：第 1~N 张全部仅截取字幕区域，适合纯粹的台词金句摘录。
  3. **完整长图竖拼**：第 1~N 张保留完整画面纵向拼接，支持横竖屏不同分辨率截图自动等宽归一化对齐。
  - **✨ 智能定位字幕**：无需联网或庞大 OCR 库，基于横向高对比度边缘密度扫描算法，毫秒级自动框出最佳字幕上下边界。
  - **🔍 单张分镜独立精修**：点击任意分镜即可单独拖拽上下沿（`0% ~ 100%` 全范围），支持 **「跟随全局」「应用全部」「保存此张」** 三种生效方式。

- **🎨 电影色调滤镜与海报级排版**
  - **4 款实时电影滤镜**：内置 **「原画色彩」「复古暖胶片」「黑白电影」「青橙冷调」** 四套基于 `ColorMatrix` 色彩空间变换的滤镜。
  - **细节排版控制**：自由调节字幕条分割线粗细（`0 ~ 24 px`）、海报外边框留白（`0 ~ 60 px`）及字幕条顶部柔和过渡暗角开关。
  - **电影出处署名水印**：支持在长图底部居中添加斜体衬线体电影出处署名（例如：`— 《星际穿越》 Interstellar —`）。
  - **三档无损画质导出**：支持 **标准 `1080P`、超清 `1440P`、原画 `2160P`** 导出至系统相册 `Pictures/SubtitleStitcher`，或一键调起微信/小红书/微博等系统分享面板。

## 🚀 二、3 步极速上手

1. **导入截图**：打开《台词拼图》，点击右上角 **「+ 导入截图」** 选择多张视频截图（或直接在手机系统相册勾选图片后点「分享 ➡️ 台词拼图」）。
2. **调整字幕区**：
   - 点击 **「✨ 智能定位字幕」** 或拖动底部 **「字幕上边界 / 字幕下边界」** 滑块，上方预览窗会实时重绘拼接效果。
   - 若某一张截图字幕位置特殊（比如双行字幕或顶部注释），点击该分镜缩略图进入 **「单张精修」**，拖动黄色标尺线或点 `±1%` 微调按钮即可单独定制，也可在下方输入框补写台词。
3. **美化与保存**：切换到 **「🎨 滤镜与间距」** 或 **「🏷️ 水印与画质」** 挑选喜欢的色调、填好剧名水印，点击右上角金色按钮 **「保存相册」** 或 **「分享」** 即可！

## 🛠️ 三、技术架构与工程特性

本项目采用 **零第三方臃肿依赖的纯正 Android SDK 原生架构（Pure Android Native + Canvas 2D 图形管线）**：

| 维度 | 工程指标与实现亮点 |
| :--- | :--- |
| **📦 极致轻量体积** | 签名版 APK 仅 **41 KB**（同类跨平台或带第三方库 App 通常为 30 MB ~ 80 MB），冷启动耗时 **`< 80 ms`** |
| **🔒 100% 离线隐私安全** | **零网络权限**（未申请 `android.permission.INTERNET`），所有图像解码、边缘检测与画布合成均在本地内存完成，绝不上传任何截图 |
| **📐 异构分辨率归一化** | 支持横屏（如 `1920×1080`）与竖屏（如 `1080×2400`）截图混拼，自动按目标画质宽度等比缩放对齐并开启双线性插值防锯齿 |
| **🛡️ 三重防 OOM 内存防线** | ① `inJustDecodeBounds` 二次采样安全解码大图；② 预览 `960px` 限流保障 60 FPS 丝滑拖动 + 导出 `2160P` 全画质双轨渲染；③ `14,000 px` 超长画布自适应缩放保护 |
| **📱 全版本与全面屏兼容** | 兼容 **Android 7.0 (API 24) 至 Android 15 (API 35)**；针对 Android 15 Edge-to-Edge 全面屏与挖孔屏通过 `WindowInsets` + `DisplayCutout` 动态安全区避让；Android 10+ 采用 `MediaStore` 分区存储免权限原子写入相册 |

## 📈 四、版本演进记录 (Changelog)

- **🌟 v1.0.0（初代核心引擎版）**
  - 完成纯原生 Canvas 2D 多图等宽归一化拼接引擎（`StitchEngine`），支持「首图全画幅 + 后续字幕」「纯字幕台词本」「完整长图竖拼」三种模式。
  - 实现横向边缘对比度密度扫描算法（`detectSubtitleBand`），支持毫秒级自动识别字幕上下边界。
  - 内置 4 款 `ColorMatrix` 电影滤镜、分割线/外边框调节、斜体衬线出处水印、1080P/1440P/2160P 三档导出及系统相册 `SEND_MULTIPLE` 多图分享导入。
- **📱 v1.1.0（真机全面屏适配与无遮挡精修版）**
  - **修复 Android 15 全面屏状态栏重叠问题**：新增 `OnApplyWindowInsetsListener` 与 `DisplayCutout` 挖孔安全区动态内边距注入，解决左上角标题与手机系统时间重合问题。
  - **重构单张分镜精修控件 (`CropRangeView`)**：摒弃原本压在裁剪线正中央遮挡台词的实心胶囊标签，升级为 **`1.5dp` 亮黄+暗虚线双色极细标尺线 + 左右外侧三角指针**，并将百分比标签外置到裁剪线外侧的废弃暗区，实现保留区内台词 **100% 零遮挡**。
- **🎯 v1.2.0（全量程自由裁剪与防跳动微调版 · 最新）**
  - **解锁 `0% ~ 100%` 全范围手势拖拽**：移除上沿 `5%` 的硬编码限制，支持上沿直达 `0%`、下沿直达 `100%`，轻松应对画面顶部人物注释或特殊位置字幕。
  - **新增独立范围读数与四宫格 `±1%` 步进微调**：将「当前字幕范围」独立为单行固定高度显示，下方配备等宽四宫格 **`[上沿 -1%] [上沿 +1%] [下沿 -1%] [下沿 +1%]`** 微调按钮，彻底消除拖动时文字换行导致的弹窗高度跳动。
